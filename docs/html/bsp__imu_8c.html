◆ bsp_imu_init()

esp_err_t bsp_imu_init ( void )

Inicializa o barramento I2C em modo mestre e acorda o chip MPU6050.

  • Define a frequência para 100kHz (Standard Mode), tira o sensor do modo sleep e parametriza a escala do acelerômetro em ±2g.
  • Retorna
    esp_err_t Retorna ESP_OK em caso de sucesso na inicialização ou códigos de falha do I2C.

◆ bsp_imu_read_accel()

esp_err_t bsp_imu_read_accel ( imu_data_t * data)

Lê os registradores de aceleração da IMU e converte os valores brutos para g.

  • Realiza uma transação única de escrita/leitura via I2C coletando os 6 bytes sequenciais de dados.
  • Parâmetros
    [out]dataPonteiro para a estrutura onde os dados convertidos serão salvos.
    Retorna
    esp_err_t ESP_OK em caso de sucesso na leitura do barramento.
