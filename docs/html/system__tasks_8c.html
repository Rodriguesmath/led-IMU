◆ system_tasks_init()

esp_err_t system_tasks_init ( void )

Inicializa os recursos do RTOS e cria as tarefas do sistema.

  • Cria internamente as filas, semáforos e mutexes necessários, inicializa a camada HAL e registra as 4 tarefas principais no scheduler do FreeRTOS.
  • Retorna
    esp_err_t ESP_OK se o hardware e os recursos do RTOS forem criados com sucesso.
